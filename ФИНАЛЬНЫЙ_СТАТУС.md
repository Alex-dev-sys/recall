## 🔄 WORKFLOW

```
1. User отправляет сообщение в Telegram:
   "Нужно отправить отчет до пятницы"
        ↓
2. Backend Worker (Pyrogram) ловит сообщение
        ↓
3. AI Pipeline обрабатывает (4 этапа):
   ├─ Extractor: "отправить отчет"
   ├─ Deduplicator: проверка дубликатов
   ├─ Deadline Parser: "пятница 23:59"
   └─ Prioritizer: "high priority"
        ↓
4. Сохраняется в Supabase (таблица tasks)
        ↓
5. Flutter App показывает задачу
```

## 🎨 ВОЗМОЖНОСТИ БОТА

### AI понимает:
✅ "Нужно сделать X до понедельника" → задача с дедлайном
✅ "Напомни позвонить маме" → напоминание
✅ "Встреча завтра в 15:00" → событие с точным временем
✅ "Договорились встретиться в пятницу" → соглашение
✅ "Срочно! Отправить документы" → высокий приоритет
✅ Находит дубликаты задач
✅ Расставляет приоритеты автоматически

### Поддерживает:
✅ Личные чаты (private)
✅ Группы (group)
✅ Супергруппы (supergroup)
✅ Каналы (channel)

### Типы задач:
- **request** - просьбы от других
- **promise** - ваши обещания
- **agreement** - договоренности
- **reminder** - напоминания себе

### Приоритеты:
- **urgent** - срочные задачи
- **high** - высокий приоритет
- **medium** - средний приоритет
- **low** - низкий приоритет
